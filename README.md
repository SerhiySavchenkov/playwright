Juice-Shop
1. Install node.js
2. Run git clone https://github.com/juice-shop/juice-shop.git --depth 1 (or clone your own fork of the repository)
3. Go into the cloned folder with cd juice-shop
4. Run npm install (only has to be done before first start or when you change the source code)
5. Run npm start
6. Browse to http://localhost:3000

Playwright tests
1. Go into the folder: ...juice-shop\test\
2. Run git clone https://github.com/SerhiySavchenkov/playwright.git
3. Go into the folder: ...juice-shop\test\playwright\
4. npm i --save-dev @playwright/test
5. npx playwright install
